# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/chauhan-harsh630/backend_node-express.git
```

## Install Dependencies

```bash
npm install
```

## Create `.env` File

```env
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```

## Start Development Server

```bash
npm run dev
```
